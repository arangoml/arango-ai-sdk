# Demo corpus

`tech_articles` holds 50 Wikipedia articles about technology companies, products, and people.
It is the corpus of the Arango Contextual Data Platform tutorials in the documentation, published as
`corpus.zip` in the [`autograph-v1` release of arangodb/docs-tutorials](https://github.com/arangodb/docs-tutorials/releases/tag/autograph-v1).

Each article names its Wikipedia source at the top. Wikipedia text is licensed under
[CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/). The Apache License 2.0 of this
repository does not apply to these files.
