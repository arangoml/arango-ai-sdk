Projects
========

You do not construct this class yourself. The client owns a
:class:`~arango_ai_sdk.projects.ProjectManager` and exposes it as
``client.project``. Its operations return
:class:`~arango_ai_sdk.models.AiProject` instances, documented in
:doc:`models`.
